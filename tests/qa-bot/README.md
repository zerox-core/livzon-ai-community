# qa-bot 知识库自检

问答机器人（`server/qa-bot`）的知识库检索自测脚本。改动 `server/qa-bot/kb.js` 或 `server/qa-bot/kb/*.md` 后跑一遍，确认用户问题都能命中正确的知识库文档。

## 用法

```bash
node tests/qa-bot/kb-test.cjs
```

跑完在本目录生成 `kb-test.out`，逐条列出每个测试问题命中的文档、得分、所属区（active=现役 / archive=档案）与身份牌（year/status）。

## 覆盖的测试问题

- 我提交的作品什么时候评审 → 应命中「比赛评审」
- 我能不能私信举办方交作品，我不会用平台 → 应命中「作品提交」
- 网页设计马拉松怎么报名 → 应命中「网页设计马拉松 9月赛季」
- 美术赛什么时候截稿 → 应命中「美术资源设计赛 秋季场」
- 怎么下载作品 → 应命中「作品巨幕」
- 我是新手，平台怎么用 → 应命中「平台新手指南」
- 投票一天能投几票 → 应命中「作品巨幕」
- 去年这个比赛是什么规则 → 时间感检索：有档案馆时应切 archive 区只搜往届资料；暂无档案时回退现役区
