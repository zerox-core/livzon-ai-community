## 四、接手步骤（另一台设备）

```bash
git pull                                   # 拉到 a95414c
cd server && npm install                   # 若 node_modules 缺失
node server/sql/run_migrate.js             # 必做！本机新增 017/018/019（18 脚本幂等）
node start.mjs                             # 启动（PG 路径自动探测，无需配 PG_HOME）
node pg-keeper.mjs doctor                  # 体检：PG/.env/回调地址/本机 IP 核对
```

**接手后必查三项**（切换“对外服务主机”相关）：

1. `server/.env` 的 **`LARK_LOGIN_REDIRECT_URI`** 改成**接手这台设备**的局域网地址（本机当前是 `http://192.168.62.53:8787/api/auth/callback`），并同步改飞书开放平台「安全设置 → 重定向 URL」白名单（需**完全一致**，含路径）。
2. `SITE_INTRANET_URL` 同样改为接手设备的地址（飞书卡片按钮指向）。
3. `.env` **不入库**，需确认接手设备已有飞书凭证（`LARK_APP_ID/LARK_APP_SECRET`）与 `DB_*`、`SESSION_SECRET`、`AGENT_TOKEN`。
