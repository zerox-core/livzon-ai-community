# 活动报名
keywords: 报名, 报名方式, 怎么报名, 如何报名, 报名流程, 报名审核, 报名状态, 报名时间, 参加活动, 参赛报名, 报名条件, 谁能报名
year: 2026

**报名入口**：平台首页点「活动大厅」，找到想参加的活动，进活动详情页点「报名」按钮，按提示填好信息提交就行。

**报名分两种玩法**（提交前请看活动详情页写明的类型）：

- **比赛制活动**（比如网页设计马拉松）：先报名 → 等管理员审核（预计 3 个工作日内反馈，通过飞书工单流转审批）→ 审核通过后在活动期间回到活动页上传参赛作品 → 参与投票和评审。注意：**报名阶段不用交作品**，报名只是拿参赛资格。
- **即参加活动**（比如 Skill 插件工坊、美术资源设计赛）：报名审核通过后，按活动安排到时参加/交作品就行，流程更轻。

**怎么查报名状态**：提交报名后，管理员审核通过前页面会显示「等待管理员审核」。审核结果也会通过站内消息通知你（右上角铃铛能看）。

**报名要钱吗**：所有活动均免费参加，用平台账号直接报名即可。

**报名被驳回了怎么办**：驳回时会附原因说明，可以按说明调整后重新报名，或在社区群里问一句。
