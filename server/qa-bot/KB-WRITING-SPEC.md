# 群问答机器人知识库 · 写入规范

> 本规范约定 qa-bot 知识库（server/qa-bot/kb/）的文档结构、命名、生命周期与检索行为。
> 目标：资料长期增多后不混乱、不过期串答、历史可查。

## 一、核心原则

**默认只答"现在"，问到"过去"才翻旧账。**

## 二、目录结构

```
kb/                        # 现役区：通用说明 + 正在进行的活动
  平台介绍.md               # 通用文档（不过期）
  活动报名.md
  活动-2026-第1届-AI绘画赛.md  # 现役活动
  archive/                 # 档案馆：已结束的活动，按年份分目录
    2025/
      活动-2025-第1届-提示词大赛.md
```

- 现役区只放：通用说明（登录、平台使用等不过期内容）+ 当前活动。
- 活动一结束，文档挪入 `archive/<年份>/`。**归档不删除**——历史问题（"去年获奖名次"）以后一定会有人问。
- 归档动作由维护者（管理员或 AI 搭档）执行，一句话触发。

## 三、文档格式（每篇必须遵守）

```markdown
# 标题
keywords: 关键词1, 关键词2, 关键词3
year: 2026
status: 进行中
---
正文（大白话，回答用户可能问的内容）
```

- `keywords`：检索打分的主要依据，覆盖用户可能的各种说法（正式名、口语、错别字常见写法）。
- `year` / `status`：文档"身份牌"，标识它属于哪个时空；通用文档写 `status: 通用`。
- 正文即答案素材：LLM 会照它组织回答，写清楚、写人话。

## 四、命名规范

- 活动类：`活动-YYYY-第N届-名称.md`
- 通用类：直接按主题命名，如 `登录注册.md`、`访问故障.md`

## 五、检索行为（防串规则）

| 用户问题 | 检索范围 |
|---|---|
| 不含时间词（"比赛怎么报名"） | 只搜现役区（通用 + 进行中活动），历史档案不参与打分 |
| 含时间词（"去年""2025年""第一届""上次"） | 专搜档案馆对应年份 |
| 两边都有命中 | 现役优先；引用历史时答案须注明"这是 YYYY 年的旧活动信息" |

> 实现状态：当前版本为扁平检索（kb/*.md 全部参与打分），archive 目录与时间感检索为已确认的下一步改造，规范先行。

## 六、生命周期

1. **建档**：办新活动 → 素材发给维护者 → 几分钟内建成新文档进现役区。
2. **现役**：活动期间随问随改，保存即生效，机器人无需重启。
3. **归档**：活动结束 → 说一声 → 文档挪入 `archive/<年份>/`。
4. **不删除**：除非内容错误，文档只挪不删。

## 七、规模升级路线

- 几十篇以内：当前方案（关键词打分 + 每问重载）足够。
- 上百篇：引入向量库 + 切片索引，两层目录结构原样迁移，旧文档打分时间衰减。
